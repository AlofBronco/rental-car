# Rental Car

A simple and convenient web application for finding and renting cars. It offers a user-friendly interface to browse available vehicles, check details, and manage your rental choices.

## Features

- Browse a catalog of cars with images and descriptions  
- Search and filter cars by type, price, or other criteria  
- View detailed information about each car 

## Installation

1. Clone the repository:  
   ```bash
   git clone https://github.com/AlofBronco/rental-car.git
   ```

2. Navigate to the project folder:
   ```bash
   cd rental-car
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

   - Open your browser and go to http://localhost:3000 (or the port shown in your terminal)
   - Browse the catalog and select a car to view details
   - Use filters to find a suitable rental
